# jorjis hasan

Personal site in the style of [ikeadrift.com](https://ikeadrift.com/) — pad drum machine, soft ground, short bio.

## Run locally

```bash
python3 -m http.server 5173
```

Then visit http://localhost:5173

## Deploy

Drop the folder on GitHub Pages, Netlify, or any static host. No build step.

Press **Q W E R T Y** (and **U** for cowbell) with sound on.
